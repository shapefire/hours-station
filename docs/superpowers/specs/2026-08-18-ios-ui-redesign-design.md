# Hours Station iOS 风格 UI 重设计

**日期：** 2026-08-18  
**状态：** 已确认  
**范围：** 全应用视觉与布局重设计（日历、当日详情、统计、设置与各类 sheet/modal）  
**非目标：** 不改 API、工时计算、状态语义、业务规则；不新增业务功能

**交互原型（视觉参考）：**

## 1. 目标与约束

### 目标

- 消除「生硬、右侧空旷、空间浪费」的观感。
- 采用接近 iOS / iPadOS **浅色** 的分组列表壳：大标题、白卡片、发丝分割线、圆角胶囊控件。
- 右侧当日区成为主内容面；左侧月历保持紧凑导航。
- 全站统一中性灰黑文字；状态色仅作点缀。

### 硬约束

| 约束 | 说明 |
|------|------|
| 功能冻结 | 现有功能全部保留（见 §2） |
| 无后端变更 | 不改接口契约、工时规则、状态枚举含义 |
| 可清理 | 旧双列布局专用 CSS、未再引用的 token / 装饰字体可删除 |
| 实现顺序 | 规格批准 → 实现计划 → 再改产品代码 |

### 已确认决策摘要

| 项 | 选择 |
|----|------|
| 范围 | 全应用（日历、统计、设置、sheets） |
| 风格 | iOS/iPadOS 浅色分组列表 |
| 当日布局 | 取消到岗/状态双列；单一分组列表 |
| 配色 | 中性灰黑主 UI；状态点缀（到岗绿 / 休息灰 / 请假橙 / 支援蓝） |
| 方案 | 方案 1：iOS 分组壳 + 紧凑月历 |

## 2. 功能冻结（保留清单）

以下能力只改呈现，不删不改语义：

| 区域 | 能力 |
|------|------|
| 日历 | 月切换、选日、月历密度/登记提示、本月登记天数与合计工时 |
| 当日 | 到岗 / 休息 / 请假 / 支援 CRUD；加班时段（含休息/请假仅加班）；整日备注；外援/试工标记 |
| 导入 | 排班文本预览与提交（解析规则不变） |
| 预览 | 当日文案预览、复制、复制到其他日期（文案格式逻辑不变） |
| 清空 | 清空当日（需确认）；清空加班（现有入口保留） |
| 统计 | 月切换；KPI（当月总工时、登记人数、出勤人天）；人员表及展开日明细 |
| 设置 | 备注预设（含导入）；花名册（含导入与删除提示）；工时扣除规则单档保存 |

**不在本次引入**新业务功能、新筛选、新图表、深色模式。

**可删除的前端资产：** 仅服务于旧「到岗 \| 状态」双列的 class/CSS；无引用的旧 `--font-display` 等装饰字体与废弃色 token。

## 3. 整体壳层（App Shell）

- **顶栏：** 分段控件「工作日历 \| 统计看板」+ 右侧齿轮进入设置。
- **背景：** 系统分组灰（约 `#F2F2F7`）；内容区白卡片浮于灰底。
- **设置：** 保持 **modal/sheet**（实现时统一一种表面形态并套用本规格视觉），**不**做成第三个顶栏 Tab。
- **统计：** 独立全页视图（切换顶栏 Tab），布局见 §6。
- **字体：** 系统栈（如 `-apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`）；主 UI 不再依赖 Source Serif / DM Sans。

## 4. 工作日历页信息架构

### 4.1 左右分栏

| 区域 | 宽度意向 | 内容 |
|------|----------|------|
| 左侧 | 窄（约 280px） | 紧凑月历 + 本月指标（本月登记、本月合计） |
| 右侧 | 剩余全部 | 当日大标题区 + 分组列表 |

- 点击月历日期 → 刷新右侧当日内容。
- 月历保持可见，**不**默认折叠；指标保留在左侧底部，不挪到统计页。
- **窄屏：** 月历叠到上方，下方仍为单列当日列表（桌面优先；窄屏细节写入实现计划）。

### 4.2 当日顶栏（对齐原型 v3）

```
[ 8月12日 周三 ]     [新增] [导入] [预览] [复制] [清空]
到岗 N · 本店 Xh · 休息 … · 请假 … · 支援 …
整日备注：…
```

- **同一行：** 左侧日期标题；右侧 **一行** 短文案胶囊按钮（新增 / 导入 / 预览 / 复制 / 清空）。
- 完整操作名用 `title` / `aria-label`（如「新增到岗」「文本导入」「预览」「复制到…」「清空当日」）。
- 摘要行与整日备注在标题行下方全宽，避免顶栏纵向堆按钮。

### 4.3 当日列表（分组列表，取消双栏）

废弃「到岗 \| 状态」左右两列（含 `.day-panel__columns` 等）。改为 **单一滚动分组列表**：

1. **到岗** — 按开始时间排序；每行：时段、姓名、工时、备注/加班等次要信息；点击进入现有编辑流。
2. **休息** — 紧凑 chips / 行 +「+ 添加」多选；占用徽章、月休息天数提示保留；有加班则展示加班信息与清空加班入口。
3. **请假** — 同休息风格。
4. **支援** — 列表行 +「+ 添加」；时段、地点等现有字段与校验不变。

空分组：实现计划统一为「显示区块标题 + 暂无」或等价轻量占位（规格不强制折叠隐藏）。

状态色 **仅** 用于行内小标记 / 左侧色条：到岗绿、休息灰、请假橙、支援蓝。

### 4.4 Sheets / 模态

新增到岗、文本导入、预览、复制到日期、设置等继续用现有 modal 流程；表面样式与壳层一致（白底、圆角、发丝线、主/危险按钮），业务逻辑不变。

## 5. 视觉 Token

| Token | 用途 | 意向值 |
|-------|------|--------|
| `--bg-app` | 页面底 | `#F2F2F7` |
| `--bg-elevated` | 卡片 / inset 列表 | `#FFFFFF` |
| `--separator` | 发丝分割线 | `rgba(60, 60, 67, 0.12)` 量级 |
| `--label` | 主文字 | 近黑 |
| `--secondary` / `--tertiary` | 次要 / 辅文字 | 中灰 / 更淡灰 |
| `--accent` | 主操作 | iOS system blue 系 |
| `--danger` | 危险操作（清空等） | 系统红系 |
| `--status-duty` / `--status-rest` / `--status-leave` / `--status-support` | 状态点缀 | 绿 / 灰 / 橙 / 蓝 |
| 圆角 | 分组卡 | 约 10–12px；按钮偏胶囊 |
| 阴影 | 卡片 | 轻或无；避免厚重投影 |

**动效：** 弹层淡入 + 轻微位移；展开行可用短高度过渡。不做装饰性大动画。

**不做：** 深色模式、强品牌色铺满、装饰插画。

旧 `tokens.css` 变量在迁移引用后删除无用项。

## 6. 统计看板

- 顶栏切换进入；页内大标题 `{年}年{月}月` + 上月/下月。
- **KPI：** 三张 inset 白卡——**当月总工时**、**登记人数**、**出勤人天**（与现有 `GET /api/stats/monthly` 字段对齐：`total_hours`、`employee_count`、`attendance_person_days`）。窄屏可改为竖排。
- **人员表：** 白底圆角分组卡内表格；列与展开日明细与现网一致（姓名、出勤/休息/支援天数、支援工时、总工时、日均等；展开行含日期、时段/状态、当日工时）。
- **不**做成与日历相同的左右分栏；无新增图表或筛选。

## 7. 设置

- 齿轮打开 modal/sheet；顶栏「设置」+ 关闭。
- **分段切换：** 备注预设 \| 花名册 \| 工时计算（对应现有三区，默认仍可落在备注预设）。
- **备注预设 / 花名册：** inset 列表 + 勾选 + 底栏删除 / 添加·导入；导入仍用嵌套弹层；花名册删除时「历史工时保留」提示保留。
- **工时计算：** 分组表单（满多少小时、扣减小时）+ 保存；文案与校验不变。
- 仅统一视觉，不改设置 API 与规则引擎。

## 8. 实现边界（给后续计划）

**改：**

- `AppShell` / 顶栏与视图切换样式
- 日历页左右栏与月历密度
- `DayPanel`：顶栏一行短按钮、取消双栏、分组列表
- 统计页 KPI 卡与人员表表面
- `SettingsModal` 与各业务 Modal 的表面样式
- `tokens.css` / `global.css`：迁 token、删双列与死代码、换系统字体栈

**不改：**

- FastAPI 路由与 schema
- 工时计算与扣除规则引擎
- `work_entry` / `day_notes` 等数据模型语义
- 排班文本导入解析与预览提交契约
- 预览复制文案拼接规则（`dayPreviewText` 等）

**验收（产品层）：**

- §2 功能清单均可在新 UI 下完成同一操作路径
- 当日顶栏标题与短按钮同一行，不因按钮换行而显著变高
- 到岗按时间排序的分组列表可读、可编辑
- 无回归：导入、预览复制、清空当日、清空加班、设置三区保存/导入

## 9. 已否决方案（记录）

| 方案 | 原因 |
|------|------|
| 仅改日历、不动统计/设置 | 已选全应用统一风格 |
| 统计也做成左右分栏 | 统计无「选日」主线，分栏无收益 |
| 设置做成第三个 Tab | 设置低频，modal/sheet 足够 |
| 左侧月历默认折叠 | 日历是主导航，需常驻 |
| 顶栏按钮堆在标题下方换行 | 垂直占用过大（已改为标题行右侧一行短按钮） |
| 主色铺满 / 强装饰 / 深色模式 | 与「中性 + 状态点缀」及本次范围冲突 |
