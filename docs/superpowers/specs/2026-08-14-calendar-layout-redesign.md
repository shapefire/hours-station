# 工作日历布局调整设计

日期：2026-08-14  
范围：工作日历页 UI 格局（日历 + 安排两列）  
相关代码：`frontend/src/pages/CalendarPage.jsx`、`frontend/src/components/DayPanel.jsx`、`frontend/src/styles/global.css`

## 目标

将工作日历页调整为清晰的三部分信息结构：

1. **日历**（左侧，略收窄）
2. **安排区**（右侧，更宽）
   - 左列：**到岗安排**（更宽）
   - 右列：**休息人员 / 请假人员 / 支援**（略窄；内容量通常较少）

在保持现有功能与数据语义不变的前提下，提升扫读舒适度，避免「一列硬堆」带来的局促感。

## 非目标

- 不改后端 API、状态枚举、占用/工时计算规则
- 不改统计看板
- 不换整体视觉主题（沿用现有 tokens：`--accent` / `--rest`、Source Serif / DM Sans）

## 选定方案

**左日历 | 右安排区；安排区内再分两列；共用标题栏；「新增到岗」归属到岗列。**

曾考虑但未选：

- 上日历下安排：日历更宽，但选日后视线上下跳，与当前使用习惯差更大
- 三列并排（日历 | 到岗 | 状态）：窄屏折行成本高，日历可读性更差

## 布局结构

### 页面级

| 区域 | 大致比例 | 说明 |
|------|----------|------|
| 月历 | `~1fr` | 相对现状收窄，仍保持月格可读 |
| 安排区 | `~1.55–1.7fr` | 成为主操作区 |

现有 `.calendar-page__workspace` 由约 `2fr / 1fr` 调整为上述比例。

### 安排区

```
┌─────────────────────────────────────────────┐
│ 共用标题栏                                   │
│ 日期 · 到岗人数/本店合计 · 休息·请假·支援摘要 │
│                    [预览] [复制到…] [清空当日] │
├──────────────────────┬──────────────────────┤
│ 到岗安排 (n) [新增到岗]│ 休息人员 …            │
│ 表单 / 草稿 / 列表     │ 请假人员 …            │
│                      │ 支援 …                │
└──────────────────────┴──────────────────────┘
```

**共用标题栏**

- 左侧：日期标题；到岗人数与本店合计工时；休息 / 请假 / 支援人数摘要
- 右侧操作仅保留**跨列动作**：预览、复制到…、清空当日
- **不包含**「新增到岗」

**内容两列（同一面板内）**

| 列 | 比例 | 内容 |
|----|------|------|
| 到岗 | `~1.35` | 列头（标题 + 人数 +「新增到岗」主按钮）；新增/编辑表单；快速复制草稿；到岗列表 |
| 状态 | `~1` | 上→下：休息人员 → 请假人员 → 支援；各自保留「+ 添加」；支援表单/编辑在本列 |

中间用低透明度竖直分割线分隔，**不**做成左右两张硬卡片。

**滚动**

- 整块安排区共用一个纵向滚动容器
- 状态列内容通常较少，不做独立滚动
- 进入新建/编辑/草稿时，仍滚到安排区内容顶部（沿用现有行为）

## 视觉

- 安排区与月历同级表面：圆角、浅底、细边框（沿用现有 day-panel / month-calendar 语言）
- 标题栏与内容区用浅分隔（淡线或极浅底差），避免厚分割条
- 到岗列表项保持现有行卡片（姓名 / 时段 / 工时）
- 休息/请假继续 chip；支援继续虚线弱化项与「不计入本店工时」提示
- 状态三块之间用小节标题间距（约 `0.85–1rem`），不套框套框
- 空态：到岗短文案；状态各小节一行淡提示
- 动效：不新增布局切换动画；保留现有粘贴条入场即可

## 交互

行为与锁定规则保持现状，仅调整控件落点：

| 动作 | 落点 |
|------|------|
| 新增到岗 | 到岗列头；表单出现在到岗列顶部 |
| 编辑到岗 / 快速复制草稿 | 到岗列 |
| 休息/请假多选添加与移除 | 状态列对应小节 |
| 支援新增/编辑/删除 | 状态列支援小节 |
| 预览 / 复制到… / 清空当日 | 共用标题栏 |
| 操作锁定 | 与现一致：表单、草稿、粘贴模式、状态同步进行中时禁用相关操作 |

## 响应式

- `≤1100px`：上日历、下安排（沿用现有断点）
- 安排区标题通栏保留；内容两列改为**单列**：先到岗，后状态（休息 → 请假 → 支援）
- 更窄宽度下按钮继续自然换行，不另做第三套布局

## 实现范围

- 主要改动：`DayPanel.jsx` 结构重组；`global.css` 中 `.calendar-page__workspace`、`.day-panel*` 布局与两列样式
- `CalendarPage.jsx` 仅在必要时微调类名/包裹，不改数据逻辑
- 验证：`cd frontend && npm run build`；手动确认宽屏两列与窄屏单列堆叠；抽查新增到岗/休息/请假/支援与预览/复制/清空

## 验收标准

1. 宽屏可见：左日历（较窄）+ 右安排；安排内到岗列明显宽于状态列
2. 「新增到岗」仅出现在到岗列，不在共用标题栏
3. 共用标题栏含日期摘要与预览/复制/清空
4. 休息、请假、支援同列纵向排列，视觉不拥挤、不套多层卡片
5. 窄屏上日历下安排，安排内先到岗后状态
6. 既有功能与锁定语义无回归
