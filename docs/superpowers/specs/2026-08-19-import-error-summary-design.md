# 文本导入预览错误摘要栏

## 问题

批量导入十几天或更多排班数据时，预览页面很长，用户必须逐一滚动才能发现哪些日期有错误、哪些行未被识别。错误提示不够醒目，未识别行藏在底部容易漏看。

## 方案

在预览区域顶部增加一个**错误摘要栏**，汇总所有问题并提供点击跳转。

## 设计

### 摘要栏位置

`roster-import-modal__preview` 内部最顶部，在日期列表之前。仅当存在入口级错误或未识别行时才渲染。

### 摘要内容

两部分，水平排列：

1. **错误汇总** — 格式：`"N处错误：M月D日、M月D日…"`，每个日期是可点击链接，点击平滑滚动到对应日期 section。
2. **未识别行提示** — 格式：`"N行未识别"`，可点击跳转到底部未识别区域。

无错误且无未识别行时不渲染任何内容。

### 视觉样式

- 浅红/浅黄警告背景色，左侧 3px 实线边框强调
- 日期链接：下划线 + pointer 光标
- 紧凑布局，padding 适中

### 滚动跳转实现

- 每个日期 `section` 通过 `ref` 回调注册到一个 `Map<work_date, HTMLElement>`
- 未识别区域同样通过 `ref` 标记
- 点击链接调用 `element.scrollIntoView({ behavior: 'smooth', block: 'start' })`

### 不变的部分

- 表格行级错误显示（红色高亮行 + 最后一列错误文字）保持原样
- 底部未识别行区域保持原样，摘要栏仅增加快捷入口

## 涉及文件

| 文件 | 变更 |
|------|------|
